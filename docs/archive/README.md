# Historical handoff archive

These documents record the original September 2026 planning and integration work.
They preserve design decisions and team handoffs, but are not current setup
instructions or proof of current functionality. Start with the root README and
current security/browser review documents instead.

- `plans/`: original implementation assignments and revisions.
- `progress/`: historical developer progress logs.
- `HANDOFF_AUDIT.md`, `integration-status.md`: snapshots of previous acceptance checks.
- `schema-drafts/`: historical SQL proposals, excluded from executable migrations.
- `login-image-provenance.json`: provenance of the unchanged login photograph.

Paths to moved archive material have been updated; other historical claims,
commands and test counts are retained as dated context.
